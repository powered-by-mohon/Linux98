# Linux98
⚠️ Project Status

Please do not install or use this operating system yet.

This project is currently under active development and is not ready for production or daily use. Many core components are still being implemented, tested, and refined.

The goal of this project is to create a hybrid operating system that combines the flexibility of Linux with the simplicity and web-focused experience of ChromeOS.

Until the first stable release is available, expect incomplete features, bugs, breaking changes, and possible data loss.

Feel free to explore the source code, follow the project's progress, or contribute, but do not install it on a machine that contains important data.
